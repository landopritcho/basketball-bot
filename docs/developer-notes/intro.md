# Intro

What is this project going to be? I don't really know yet. I've played around with far
too many ideas related to sports stat aggregation and scrapers. I've attempted numerous
times to build out a version of my sports website, none of which I've been fully happy
with. I've written out dozens of plans for machine learning projects related to sports
performance forecasting, yet never get past actually getting a data collection pipeline
thrown together to begin. Too much of my time has been wasted trying to solve the same
problem over and over, with new excuses popping up each time as to why that attempt
never worked out.

This project is an attempt to finally build out my vision for a basketball statistics
"bot". What exactly does bot mean in this context? Well, there's a lot of different
responsibilities that I think this program should be able to fulfill. For starters, it
needs to be able to efficiently and successfully scrape all desired datapoints a user
could reasonably be interested in relating to the sport of basketball, specifically
Men's College Basketball. The specifics for what this data actually is will be laid out
in another more technical document, however this is the primary and initial object for a
bot to begin being useful.

The second responsibility is to be able to present that data in an efficient and
organized manner. Not only is it responsible for procuring the information, it needs to
have the ability to present the data that it has gathered. This could be via CLI, API,
or any other reasonable method for conveying information to the user.

That's pretty much the bare minimum. While there's tons of other cool features that I
would love to build out in my ideal basketball bot, these two responsibilties are the
essentials before I would consider the bot a success.

For the sake of keeping the project introduction short and sweet, this is going to be 
it. This right here is pretty much the entire project goal. Either I can successfully 
build this out, or I start another repo 2 months down the road and start all over again.
Hopefully this is the last version of this intro that you'll ever have to read.
