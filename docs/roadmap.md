# Roadmap

This is going to include all of the near- and long-term project goals that I can think
of, roughly in order of execution goal. This should change often. Will be a very rough
document.


## What are the core data "types" we need to be fetching and storing?
1. Teams - All active Division 1 Men's NCAA basketball teams
    - All relevant information related to a team

2. Schedule - Upcoming games between two teams
    - Should be stored with a generic ID, not tied to either team specifically

3. Roster - Collection of all active players on a given team

4. Player - General information, team history, historical statistics

5. Game - Historical (completed) games and their statistics
    - Need to have team and player statistics per-game
